# 01: I/O & Filesystem

Dead-simple filesystem operations centered on `File`, `Dir`, `Path`, and `Link`.

---

## 1. File & Directory

```dart
final file = File('data.txt');

// Read & Write
final text = await file.text();
final data = await file.bytes();
await file.write('Hello world');

// Ops
await file.copy('backup.txt');
await file.move('archive.txt');
await file.drop(); // deletes file

final dir = Dir('src');
await dir.make(); // mkdir -p
await dir.drop(); // rm -rf
final files = await dir.find('*.dart'); // recursive glob
```

---

## 2. Links & Filesystem Metadata

Full support for symlinks and hardlinks with 1-word methods:

```dart
// Create symlink: link -> target
await Link('shortcut.txt').make(target: 'data.txt');

// Check & Resolve
print(Path('shortcut.txt').isLink);  // true
print(await Path('shortcut.txt').target); // 'data.txt'

// Hardlink
await File('data.txt').hardlink('hard_backup.txt');

// Permissions (octal or symbolic)
await File('run.sh').chmod(0755);
```

---

## 3. Watching & Temp

```dart
// Watch directory changes in realtime
await for (final event in Dir('src').watch()) {
  print('${event.type}: ${event.path}'); // create, modify, delete
}

// Create unique temporary file or directory
final tmpDir = await Dir.temp();
final tmpFile = await File.temp(ext: '.bin');
```

## 4. Advanced Use Cases

### 4.1 Atomic File Swap (Zero Downtime)
Writing directly to an active file risks readers observing corrupted or half-written bytes. Atomic writing safely writes to a temp sibling and performs an atomic swap:

```dart
// Writes to sibling .tmp then atomic-renames over target
await File('config.json').atomic('{"version": 2}');
```

### 4.2 Safe Symlink Traversal (Zip-Slip & Escape Protection)
When unpacking archives or following user-supplied paths, symlinks pointing outside the root must be rejected:

```dart
final root = Path('/app/storage');
final target = await (root / userSuppliedPath).resolve();

if (!target.starts(root)) {
  throw Exception('Path traversal detected!');
}
```

### 4.3 Live File Watcher to Build Pipeline
```dart
// Auto-recompile when source files change
Dir('lib').watch().listen((e) async {
  if (e.path.endsWith('.dart')) {
    print('Changed: ${e.path}. Rebuilding...');
    await Process.run('dart', ['compile', 'exe', 'bin/main.dart']);
  }
});
```
